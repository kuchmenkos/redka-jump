# Редька Джамп

Вишитий піксельний дудл-джамп: Редька піднімається хронологією кенселів 2022–2026 до мільйона підписників, стрибаючи по ярликах, які на нього вішають.

Уся гра — один файл `index.html` без збірки й залежностей (тільки Google Fonts). Відкрий його в браузері або роздай будь-яким статичним хостингом.

## Керування

- Телефон: тримай ліву або праву половину екрана.
- Клавіатура: стрілки або A / D, Enter чи пробіл — старт.

## Структура `index.html`

Код усередині одного `<script>`, розділи йдуть по порядку:

| Розділ | Що там |
|---|---|
| `sound` | синтезовані звуки через WebAudio (`SFX`) |
| `pixel sprites` | сітки спрайтів Редьки, хейтерів, бонусів; `buildSprite()` малює їх у canvas |
| `LOOKS` | костюми й пороги їх відкриття |
| `content` | усі тексти: `COMMON`, `ZONES` (етапи з ярликами й скандалами), `MINUS`, `MOVERS`, `FAKES`, `CITIES`, `ENEMIES` (фрази, причини фіналу), `STOMP_Q`, `SPRING_Q` |
| `EUNLOCK` | з якої кількості підписників з'являється кожен хейтер |
| `genStep()` | генерація рівня: латки, фейки, бонуси, хейтери, антракти |
| `update()` | фізика, колізії, механіки хейтерів, комбо, польоти |
| `draw*()` | рендер латок, хейтерів, Редьки, фону з мотивами етапів |
| `scene()` / `makeCard()` | фінальні ілюстрації й картка для шерингу |

## Баланс

- `SC` — скільки підписників дає один піксель висоти (зараз 15).
- Пороги етапів: `ZONES[].from`. Костюмів: `LOOKS[].at`. Хейтерів: `EUNLOCK`.
- Частоти появи — у `genStep()` через `ramp(gs, від, до)`.
- Ліміт хейтерів на екрані — `ecap` у `genStep()`.
- **Шакалячий експрес** — рідкісний політ на ракеті з 250 000, кулдаун 200 000, `fly=450`.
- **В гостях у Гордона** — один кидок 34% після 777 000 за катку (`GORDON_AT`, `GORDON_P`). Якщо предмет не підібрати, другого не буде. Політ золотий, триває стільки, скільки інтро на швидкості 1.2.

## Піксель-арт

У `art/` лежать Python-скрипти (потрібен Pillow), які генерують сітки спрайтів у JSON і прев'ю-PNG:

- `enemies.py` → хейтери (`EGRID`, `EPAL` в `index.html`)
- `items.py` → ракета, паровоз, конверт, тред (`IGRID`)
- `motifs.py` → вишиті мотиви етапів на фоні (`MOTIF`)

Скрипти пишуть результат у `/tmp/claude-0/art/` — поправ шляхи під себе. Після змін встав новий JSON у відповідну константу в `index.html`.

Окремо від піксель-арту, гра тягне фото з диска:

- `art/felix-face.png` — обличчя Редьки поверх піксельного тіла
- `art/gordon/1.webp` … `5.webp` — портрети, що крутяться в режимі Гордона
- `art/gordon-intro.mp3` — інтро цього режиму (`playbackRate` 1.2)

## Шеринг

Кнопка «Поділитись» генерує PNG 1080×1350 і пробує `navigator.share`. Якщо браузер не дає — показує картинку, щоб її можна було зберегти утриманням. У claude.ai для цього використовувалась можливість `downloads`; на власному хостингу працює звичайний Web Share.
