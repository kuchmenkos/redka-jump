# Редька Джамп

Піксельний дудл-джамп: Редька піднімається хронологією кенселів 2022–2026 до мільйона підписників, стрибаючи по ярликах, які на нього вішають.

Уся гра — один файл `index.html` без збірки й залежностей (тільки Google Fonts). Картинки й звук лежать в `art/`, тож гру треба віддавати статичним сервером разом із цією папкою (наприклад, `python3 -m http.server`), а не відкривати як файл.

Онлайн: [https://redkajump.fun/](https://redkajump.fun/). Деплой — GitHub Pages з `main` (Actions). Репозиторій має бути **публічним** (або GitHub Pro для private Pages). «Поділитись» додає `https://redkajump.fun/` (або поточний origin, якщо відкрито не з localhost).

### DNS для `redkajump.fun`

1. Apex `redkajump.fun` — записи **A**: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153` (за бажанням **AAAA** GitHub Pages).

## Керування

- Телефон: тримай ліву або праву половину екрана. Сторінка адаптована під телефон (`viewport`, `100dvh`, safe-area), браузерні жести на полі вимкнені.
- Клавіатура: стрілки або A / D, Enter чи пробіл — старт.

## Структура `index.html`

Код усередині одного `<script>`, розділи йдуть по порядку:

| Розділ | Що там |
|---|---|
| `sound` | короткі синтезовані звуки через WebAudio (`SFX`) |
| `pixel sprites` | сітки спрайтів; `buildSprite()` малює їх, `makeChar()` ставить піксельне обличчя на тіло без голови, `drawChar()` малює персонажа |
| `LOOKS` | костюми гардероба: `cost` у квитках, `at` лише для міграції старих сейвів |
| `content` | усі тексти: `COMMON`, `HOT`, `ZONES`, `MINUS`, `MOVERS`, `FAKES`, `CITIES`, `ENEMIES`, `STOMP_Q`, `SPRING_Q` |
| `BG_FILES` / `drawBg()` | фон етапу з `art/bg/`, який прокручується знизу вгору протягом етапу і плавно змінюється на наступний |
| `placePlat()` / `genStep()` | розкладка латок і генерація рівня: латки, фейки, бонуси, хейтери, антракти |
| `hate stats` | `hateLog`, `RANKS`, `rankNow()` — лічильник ярликів і жартівливі звання |
| `redkaStats` / `redkaAch` | пожиттєва статистика й відкриті ачивки в `localStorage` |
| `update()` | фізика, колізії, відклеювання латок, механіки хейтерів, комбо, польоти, черга тостів |
| `scene()` / `makeCard()` | фінальні ілюстрації (теж кодом) і картка для шерингу |

## Баланс

- `SC` — скільки підписників дає один піксель висоти (зараз 15).
- Пороги етапів: `ZONES[].from`. Костюми купуються квитками (`LOOKS[].cost`: 12, 20, 32, 48, 72, 96, 128, 160, 200; «Без піджака» безкоштовно). Хейтерів: `EPOOL` по зонах (Суми — нікого, Львів — Стукач, далі + Мовна, Тредс, Скасовувач, Комсомол).
- Латки: шрифт `PFONT` (13), висота `PH`, ширина 60–160 px. Вертикальна щілина `rnd(72,88)+80*ramp` (старт ~80 px, пізно ~150–168, апогей стрибка ~177). `placePlat()` не дає новій латці перекрити попередню по горизонталі і пускає через центр поля щонайбільше одну з чотирьох.
- Ярлик відклеюється після 2 стрибків (`platLife` завжди 2, включно зі скандалом і «ПЕРШИЙ ЖАРТ»). Комбо збивається, якщо 3 с не рухатися вбік.
- Хейтери: кап 1/2/3/4 після 60k, 140k, 280k, 550k; шанс кроку 8%→28%. Ставляться біля шляху вгору, червона тінь і плашка, репліка змінюється на дії. Усіх п’ятьох можна топнути зверху (`stompHater`): `+2500` і цитата з `STOMP_Q`. Боковий удар убиває.
- **Шакалячий експрес** — рідкісний політ на ракеті з 250 000, кулдаун 200 000, `fly=450`. Фелікс у ПНБ (`felix-fly`), нахил, шлейф, слабка тряска камери.
- **В гостях у Гордона** — після 300 000 кожна звичайна нерухома латка (не антракт, не в польоті) кидає 34% (`GORDON_AT`, `GORDON_P`), поки не випаде предмет. Один раз за катку: якщо не підібрати, другого не буде. Дев’ять фото летять з різних країв крізь центр, без повторів підряд. Політ золотий з тим самим обличчям у ПНБ, легка тряска і смуги швидкості; триває стільки, скільки інтро на швидкості 1.2, гучність 70%.
- **Скасовані міста туру** — з ~40 000 (`CITY_FROM`) по всіх етапах, не лише Одіссея. За забіг спавниться щонайбільше 15 унікальних залів (`CITIES`, `CITY_CAP`). Лічильник `скасовано N з 12`. Ачивки один раз за забіг: 3 («Хет-трик туру», +8 000), 7 («Сім залів», +15 000), 12 («Тур зірвано», +25 000).
- **Квитки** — піксельний квиток над звичайною латкою після ~12 000, кулдаун ~8 латок, шанс ~10%→~16%. Підбір одразу пише `STATS.tickets` у `localStorage` (смерть не з’їдає). За 80–150k очікувано 4–7 квитків, ~300k — 10–14, глибокий тур — 20–28.
- Після «Стрибати» (або «Ще раз») показується сплеш «ХТО НЕ СКАЧЕ - ТОЙ МОСКАЛЬ»; тап або ~1.8 с запускає гру.
- HUD: один ряд нашивок — рахунок | квиток | «Меню». Комбо `×N` лише коли множник > 1, рекорд — золота стрічка. Підказка ◀ ▶ (`STATS.steerN < 3`, кремовий диск ~0.7) після сплешу з грейсом 0.5 с; зникає після вводу, ~4 с або на паузі.
- Пауза: кнопка «Меню» у HUD. Картка «Пауза» — продовжити, гардероб, звук/музика, «На старт» без фіналу. `Esc` / `P` і згортання вкладки вмикають паузу. `update` і `draw` лише при `mode==='play'`.
- Звук ♪ і музика ♫ — на старті й у паузі, не на ігровому полі.

## Арт

- `art/faces/*.png` — піксельні обличчя на рідній сітці: `felix` (Редька в грі, на старті й у гардеробі), `felix-fail` (шок на всіх фінальних сценах після фейлу), `felix-fly` (ПНБ під час Шакалячого експресу і Гордона), `stuk`, `koms`, `threads`, `cancel`. Мовний патруль малюється піксельною сіткою без фото. Положення голови задають `REDKA_FACE` і `EFACE`.
- `art/bg/<етап>.webp` — сім ілюстрованих піксельних фонів, по одному на етап з `ZONES`. Фінальні сцени `scene()` беруть `art/ends/<причина>.webp` і кладуть штампи зверху; якщо файл ще не вантажився — старий canvas.
- `art/gordon/1.webp` … `9.webp` — портрети, що пролітають у режимі Гордона; `art/gordon-intro.mp3` — його інтро.
- `art/springy-lead.mp3` — головна музика на фоні, цикл, гучність 63%. Окрема кнопка ♫ вимикає лише її; ♪ лишає звуки стрибків і Гордона. Під час візиту Гордона фон стихає. Перший тап на старті праймить і грає фон.
- `art/enemies.py`, `art/looks.py`, `art/items.py` (потрібен Pillow) генерують сітки `EGRID`/`EPAL`, унікальні костюми (`CLOWN`, `ODYSSEY`, оновлений `REDKA`) і `IGRID`. Хейтери з PNG-обличчям малюються без піксельної голови; мовний патруль — повний піксельний спрайт.

## Досягнення й гардероб

Кнопка «Досягнення N/22» на старті відкриває колекцію: сітка з 22 мемних досягнень (іконки в `art/achs/`, лічильник з `ACH.length`) і гардероб 10 костюмів. Некуплене — сірий силует «Без піджака», `???` і ціна в квитках, без назви й кольору. Куплене — спрайт, назва, «Одягнути» / «На тобі». Старі сейви з `STATS.looks` або рекордом ≥ `LOOKS[].at` отримують луки даром. Нові досягнення виходять тостом під час забігу і блоком на фіналі. Статистика живе в `localStorage` як `redkaStats` (`tickets`, `owned`, `wear`), відкриті — як `redkaAch`. «Золотий хлопчик» і «Повний гардероб» — за куплені костюми.

## Фінал і шеринг

Кожен перший стрибок на ярлик записується в `hateLog`. Фінальний екран має вкладки «Результат» і «Зібрано хейту» з топ-5 ярликів, званням і розібраними хейтерами.

Кнопка «Поділитись» генерує PNG 1080×1350 зі званням і топ-3 і пробує `navigator.share` (з файлом, якщо браузер вміє). Якщо шеринг лише текстом або його немає — показує картинку, щоб її можна було зберегти утриманням. Текст шерингу копіюється в буфер разом із посиланням на гру. Окремої кнопки «Зберегти картинку» немає. На фіналі рядок квитків: «Квитки цього забігу +N · усього M».
